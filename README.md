👕 Veste+ — Sistema de Doação de Roupas

Plataforma que conecta doadores e pessoas que precisam de roupas, promovendo solidariedade e impacto social.

🌍 Sobre o projeto

O Veste+ é um sistema web desenvolvido para facilitar a doação de roupas, conectando:

👤 Doadores (pessoas que doam roupas)
🧥 Clientes/Recebedores (pessoas que recebem doações)
📦 Instituições e campanhas sociais

A plataforma permite cadastro de usuários, autenticação, catálogo de roupas, registro de interesse e acompanhamento de doações.

🚀 Funcionalidades
👤 Usuários
Cadastro de doadores e clientes
Login com autenticação por perfil
Verificação de cadastro via código
Edição de perfil e endereço
🧥 Doações
Cadastro de roupas por doadores
Upload e exibição de imagens
Organização por campanhas
📦 Cliente (recebedor)
Visualização de catálogo de roupas
Registro de interesse em peças
Histórico de solicitações
🔐 Segurança
Verificação de conta por código
Controle de sessão
Separação de perfis (doador / cliente)
🛠️ Tecnologias utilizadas
PHP 8+
CodeIgniter 4
MySQL
HTML5
CSS3
JavaScript (Vanilla)
Bootstrap (parcial)
